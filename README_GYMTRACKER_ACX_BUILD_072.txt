GYMTRACKER ACX · BUILD 072

IMPORTACIÓN CON IA
- Prompt preparado para copiar en ChatGPT, Gemini u otra IA.
- Formato de respuesta explícito y fácil de revisar.
- Admite una o varias rutinas en una sola importación.
- Detecta nombre, día, ejercicios, series, repeticiones, peso, descanso y modo.
- Vista previa obligatoria disponible antes de confirmar.
- Puede asignar automáticamente las rutinas a los días indicados.
- Los nombres no reconocidos no se pierden: se marcan para revisión y se conservan como ejercicios personalizados.

PLANIFICACIÓN SEMANAL
- Los siete días aparecen como tarjetas ACX claras para móvil.
- Tocar una tarjeta abre la asignación existente.
- Mantiene planificación fija o semana independiente.
- En semana independiente permite repetir la semana anterior.
- No cambia el motor de entrenamientos, guardado ni historial.
